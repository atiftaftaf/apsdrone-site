Model Notes Support

Mark up your own 3D models on iPad and iPhone. View on the App Store

Contact Support

Email info@apsdrone.com with your app version, device model, iOS or iPadOS version, and a description of the issue. Please do not send passwords, financial information, or confidential project files. If a sample is needed, use a small model you have permission to share.

Models and Projects

Import from Files using Import model. Supported files include self-contained GLB and glTF, recognized embedded-model HTML, standalone OBJ and STL, and triangle-mesh PLY. Separate external textures and materials are not imported. Not every HTML page is a supported model.

Projects save on your device. Keep original files separately and export important projects before removing the app or changing devices. Exported HTML opens as a read-only viewer and can be reimported into Model Notes.

iPad and iPhone

Drawing and measuring need Apple Pencil on a compatible iPad. Fingers rotate, pan, and zoom the model.

iPhone does not support Apple Pencil. On iPhone you can open models, read notes, edit note text and photos, review existing measurements, and export. From version 1.0.1 the drawing and measuring tools are not shown on iPhone. To continue a project on another device, export an annotated HTML file and import it there.

Measurements

Check the model's units and calibrate against a known length before using measurements. Results depend on the source geometry and scale. Model Notes is a visual review tool, not certified surveying, engineering, or safety-critical software.

Photos, Storage, and Exports

Use the note editor to select a photo or take one with the camera. Camera access is requested when needed. Permissions can be changed in device Settings.

HTML, PDF, and video exports create separate copies. Settings > Clear Cache & Exports removes temporary export copies, not saved models. Close the current model before clearing exports.

Purchases

Purchases and refund requests are handled by Apple. Visit Apple's purchase support for a purchase-related issue.
